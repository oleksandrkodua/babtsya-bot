# Бабця з альтанки · Telegram-бот на Cloudflare Workers

Експериментальний Telegram-бот для сусідської групи. Двічі на день робить вижимку чату у вигляді короткої п'єси в дусі Леся Подерв'янського з афішею-картинкою, між випусками бурчить, а коли її гукнути тегом — відповідає сама.

Працює на Cloudflare без власного сервера (Worker + D1 + Workers AI). Аналітики немає.

> Персонаж і жарти розраховані на конкретну сусідську групу й містять лайку (так задумано). Перед використанням у своїй групі перечитайте `prompts/` і змініть під себе.

## Що вміє

- **Вижимка-п'єса.** Обідня рівно о 13:00, якщо з попереднього випуску набралось ≥ 50 повідомлень (одна перевірка); вечірня о 22:00 при ≥ 50 (перевірки до 23:30). Не набралось — повідомлення переходять у наступний випуск, порожній день — мовчання.
  - Вікно вижимки — усе з попереднього випуску. Ніч 22:00–05:00 на початку вікна: ≥ 10 повідомлень — окрема перша сцена, менше — одна ремарка.
  - Сцени лише для дворових історій; новини про зовнішній світ — одна ремарка перед мораллю.
  - Шапку («П'єса на одну дію», «Дія відбувається…»), склад «Ім'я «підпис» — роль» у випадковому порядку й перекличку «Також у дворі галасували…» збирає код, а не модель.
  - Перед кожною п'єсою — афіша: Gemma описує сцену, FLUX.1 schnell (Workers AI) малює в яскравому наївному стилі, під картинкою — назва. Не вийшла картинка — п'єса йде без неї.
- **Бурчання** кожні 90 хв 08:00–18:30 (`prompts/grumbles.txt` — зразок стилю й запас). Після обідньої п'єси — тиша до 15:00, з 20:00 до 08:00 мовчить (крім опитування, вечірньої п'єси й відповідей на тег).
- **Відповіді — лише на тег** `@бота`. Реплай, `/команда` й слова «бабця», «бот» не спрацьовують. Ланцюжок: розбір розмови (20 останніх повідомлень) → 3 чернетки → суддя-модель ставить оцінку → якщо слабко, другий раунд → коректор. Поки думає, у чаті «друкує…». Слово після тегу обирає тему; на окремі прізвища відповідь фіксована. Теми (`REPLY_TOPICS`): обід, хахалі, погода, гроші, здоров'я, хороше, плітки, пророцтво, а ще:
  - **рецепт** — справжній робочий рецепт до 12 рядків;
  - **таро** — три вигадані побутові карти («Сусід з перфоратором») і що з них виходить;
  - **гадання** — щоразу один із 5 способів (кавова гуща, долоня, карти, віск чи цибуля, боби);
  - **гороскоп** — один із 5 видів (на день, на тиждень, любовний, фінансовий, для всього двору);
  - **порада** — тригер українською й російською (порада, совет, посоветуй, порекомендуй, підкажи, подскажи…), один із 5 видів. Вид усередині теми обирає код, щоб не повторювались.
  - Адресат: реплай іншому учаснику + тег бабці → вона відповідає йому, якщо повідомлення тегає його, називає його на ім'я (чи форму з `ALIASES`) або каже «вразумі / буль / заспокой / видай / пригости» чи «скажи / дай / розкажи / поясни» + «їй / йому / їм» (`pointsAtOther`). Інакше адресата обирає розбір розмови.
  - Для «рецепт» і «хороше» тон м'який, подерв'янський, без грубощів.
  - Спотворені моделлю імена учасників виправляє код (`fixNames`) — і в п'єсах, і у відповідях (наприклад, «Ніна» замість «Нена» чи «Lida» замість «Ліда»).
- **Опитування** «зрада чи перемога» о 21:00; о 22:00 закривається, вердикт дня йде ремаркою у вечірню п'єсу, у неділю додається підсумок тижня.
- **Підколка** `TEASE` (необов'язкова): раз на 2 дні у випадкову пів години 16:00–23:00, з картинкою із запасу. Картинки малюються вночі; комітет із трьох питань до Gemma 4 оцінює їх, найкраща невикористана йде в чат. Картинка зберігається в D1 (`pics.data`) до відправки.
- **Ручні команди** через `/run` (заголовок `X-Telegram-Bot-Api-Secret-Token`): `manual` (вижимка; `keep=1` — не видаляти повідомлення), `say`, `grumble`, `poll`, `sample`, `poster`, `tease`, `stock`. Невідомий `kind` дає 400 й нічого не робить.

Уся обробка тексту (фільтри репостів, редакція номерів і карток, коректор, довжина) лежить у [src/pipeline.js](src/pipeline.js) і перевіряється без Cloudflare та Telegram.

## Вимоги

- Node.js 24 або новіший.
- Акаунт Cloudflare; `wrangler` бере `npx`, глобально він не потрібен.
- Бот від `@BotFather` з вимкненим Group Privacy.

## Налаштування

У [wrangler.toml](wrangler.toml) лишено заглушки. Підставте свої значення **лише локально** й не коміть їх у публічний репозиторій:

| Що | Де взяти |
|---|---|
| `database_id` | вивід `npx wrangler d1 create babtsya` |
| `GROUP_CHAT_ID` | id вашої супергрупи (`-100…`), див. [DEPLOY.md](DEPLOY.md), етапи 2 і 6 |
| `TEST_CHAT_ID` | id вашого особистого чату з ботом |
| `FEMALE_NAMES` | жінки групи за іменем у Telegram, через кому (у копії порожньо: усі — чоловіки) |
| `ALIASES` | необов'язково: імена, якими учасників кличуть у житті, `Ім'я в Telegram: форма, форма; …` (напр. `Lida: Ліда, Ліді, Лідусю; Taras: Тарасик`). У тезок береться до уваги лише той, кому реплай (у копії порожньо) |
| `TEASE` | необов'язково: підколка раз на 2 дні (у копії порожньо — вимкнена) |
| `TELEGRAM_BOT_TOKEN`, `WEBHOOK_SECRET` | **не у файлах**: `npx wrangler secret put …` |

Порада: тримайте робочу копію з реальними значеннями в окремій приватній папці, а в публічний репозиторій викладайте лише цю версію із заглушками.

## Перевірка й розгортання

```sh
npm test                                 # самоперевірки pipeline.js і poll.js
npx wrangler login
npx wrangler d1 create babtsya
npx wrangler d1 execute babtsya --remote --file=schema.sql
npx wrangler secret put TELEGRAM_BOT_TOKEN
npx wrangler secret put WEBHOOK_SECRET
npx wrangler deploy
```

Далі один раз встановіть webhook (`setWebhook`, етап 4 у [DEPLOY.md](DEPLOY.md)). CI ([.github/workflows/test.yml](.github/workflows/test.yml)) запускає `npm test` на кожен push.

## Дані та приватність

- Бот читає повідомлення групи й зберігає їх у D1 лише до наступного випуску; після публікації вони видаляються. Таблиці: `messages` (черга на вижимку), `digests` (план випуску), `people` (ім'я → Telegram id для справжніх тегів), `polls` (опитування дня й підрахунок), `pics` (запас картинок для підколки; сама картинка лежить у D1 до відправки), `usage` (лічильник відповідей на тег за добу).
- Текст обробляє модель Cloudflare Workers AI. Попередьте учасників групи.
- Номери телефонів і картки редагуються перед відправкою в модель.
- Картинки не зображають реальних людей і без тексту.
- Бот не бачить видалень: видалене повідомлення все одно може потрапити у вижимку.

## Межі

- Історію до додавання бота Bot API не віддає.
- Текстова модель `@cf/google/gemma-4-26b-a4b-it`, картинки `@cf/black-forest-labs/flux-1-schnell`. Безкоштовний ліміт ~10 тис. нейронів на добу; орієнтир: ≈ 300 на п'єсу, ≈ 60 на картинку, ≈ 120–220 на відповідь на тег.
- Бюджет нейронів: відповіді на тег рахуються за добу (таблиця `usage`). Після 25-ї за день бот переходить в економний режим — один чернетковий прохід без судді, — щоб п'єсам вистачило нейронів.
- Відповідь на тег мусить вкластися в ~30 с життя `waitUntil`: другий раунд і коректор запускаються, лише якщо лишається час.
