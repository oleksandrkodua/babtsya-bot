# Бабця з альтанки · Telegram-бот на Cloudflare Workers

Експериментальний Telegram-бот для сусідської групи. Двічі на день робить вижимку чату у вигляді короткої п'єси в дусі Леся Подерв'янського, між випусками бурчить, а на пряме звернення відповідає сама.

Працює на Cloudflare без власного сервера (Worker + D1 + Workers AI). Аналітики немає.

> Персонаж і жарти розраховані на конкретну сусідську групу й містять лайку (так задумано). Перед використанням у своїй групі перечитайте `prompts/` і змініть під себе.

## Що вміє

- **Вижимка-п'єса.** Обідня 13:00–16:00, щойно набралось ≥ 100 повідомлень; вечірня о 22:00 при ≥ 50. Порожній день — мовчання.
- **Бурчання** кожні 90 хв 08:00–21:30 (`prompts/grumbles.txt`), плюс раз на день фраза про «сусіда».
- **Відповіді.** Лише на реплай на повідомлення бота, тег `@babtsya_z_altanky_bot` або `/команду`. 1 з 3 відповідей грубо, 2 з 3 філософськи.
- **Опитування** «зрада чи перемога» щодня о 21:00 (підсумок тижня не підключений).
- **Ручні команди** через `/run`: `say`, `grumble`, `poll`, `manual` (із заголовком `X-Telegram-Bot-Api-Secret-Token`).

Уся обробка тексту (фільтри репостів, редакція номерів і карток, коректор, довжина) лежить у [src/pipeline.js](src/pipeline.js) і перевіряється без Cloudflare та Telegram.

## Вимоги

- Node.js 24 або новіший.
- Акаунт Cloudflare; `wrangler` бере `npx`, глобально він не потрібен.
- Бот від `@BotFather` з вимкненим Group Privacy.

## Налаштування

У [wrangler.toml](wrangler.toml) лишено заглушки. Підставте свої значення **лише локально** й не коміть їх у публічний репозиторій:

| Що | Де взяти |
|---|---|
| `database_id` | вивід `npx wrangler d1 create babtsya` |
| `GROUP_CHAT_ID` | id вашої супергрупи (`-100…`), див. [DEPLOY.md](DEPLOY.md), етапи 2 і 6 |
| `TEST_CHAT_ID` | id вашого особистого чату з ботом |
| `TELEGRAM_BOT_TOKEN`, `WEBHOOK_SECRET` | **не у файлах**: `npx wrangler secret put …` |

Порада: тримайте робочу копію з реальними значеннями в окремій приватній папці, а в публічний репозиторій викладайте лише цю версію із заглушками.

## Перевірка й розгортання

```sh
npm test                                 # самоперевірки pipeline.js і poll.js
npx wrangler login
npx wrangler d1 create babtsya
npx wrangler d1 execute babtsya --remote --file=schema.sql
npx wrangler secret put TELEGRAM_BOT_TOKEN
npx wrangler secret put WEBHOOK_SECRET
npx wrangler deploy
```

Далі один раз встановіть webhook (`setWebhook`, етап 4 у [DEPLOY.md](DEPLOY.md)). CI ([.github/workflows/test.yml](.github/workflows/test.yml)) запускає `npm test` на кожен push.

## Дані та приватність

- Бот читає повідомлення групи й зберігає їх у D1 лише до наступного випуску; після публікації вижимки вони видаляються. Окремо лежать `digests` (план випуску) і `people` (ім'я → Telegram id для справжніх тегів).
- Текст обробляє модель Cloudflare Workers AI. Попередьте учасників групи.
- Номери телефонів і картки редагуються перед відправкою в модель.
- Бот не бачить видалень: видалене повідомлення все одно може потрапити у вижимку.

## Межі

- Історію до додавання бота Bot API не віддає.
- Модель `@cf/google/gemma-4-26b-a4b-it`; безкоштовний ліміт ~10 тис. нейронів на добу (≈ 330 на вижимку, ≈ 20 на відповідь).
- Опитування не рахуються, тому підсумку тижня немає.

| `DEPLOY.md` | розгортання від нуля |
