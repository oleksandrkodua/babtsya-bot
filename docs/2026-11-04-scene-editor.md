# Редактор і структура сцен — 04.11.2026

Після другого приватного preview погоджено три зміни: замінити повторний переказ розвитком діалогу, посилити слабкі фінали й прибирати репліку після панчлайна, коли вона не містить важливих фактів. Короткий діалог без матеріалу на сцену стає ремаркою.

## Конвеєр

1. Письменник створює чернетку з незмінним основним стилем бабці та вибраним жанром.
2. Код відновлює імена. Один редакторський прохід отримує жанр, план, доступний письменнику чат і сцени. Повертає JSON з новим текстом лише змінених сцен. Чинний механізм AI може повторити невдалий або обірваний виклик один раз; додаткового редакторського циклу немає.
3. Код приймає тільки правки наявних сцен, що не вводять нових співрозмовників сцени, зберігають набір чисел і дають щонайменше три репліки між мінімум двома учасниками. Шапка, заголовки сцен, мораль і зовнішні ремарки не замінюються. Некоректна, надмірно довга або непридатна правка відхиляється; залишається початкова сцена.
4. Далі працюють наявні перевірки копіювання, авторства слів, коректор та обмеження довжини. Після всіх проходів код перетворює діалоги коротші за три репліки й монологи на ремарки, зберігаючи їхній текст; решта сцен перенумеровується.

Редактор не має вигадувати факти, реальні вчинки, погляди, причини чи розгадки. Якщо слабкий хвіст містить важливий факт, зміст треба перенести раніше, а не видаляти. Перевірка чисел — частковий запобіжник; відповідність змісту джерелу повністю кодом не доводиться.

## Витрати й робочий режим

- До одного редакторського проходу на п'єсу, максимум 2000 вихідних токенів за спробу; якщо немає сцен, виклику немає. Фактична витрата записується чинним обліком AI; модель квоти не змінена.
- Додатковий виклик витрачає нейрони зі спільного бюджету. Реальну вартість і вплив на запас для вечірнього випуску ще не виміряно.
- Розклад, груповий режим, відповіді на тег і правила приватного preview не змінені. Ручні генерації для перевірки цієї зміни не запускалися.

## Перевірка

`npm test`: 74 тести плюс самоперевірки. Перевіряються прийняття редакторських правок, ранній панчлайн, збереження чисел, відхилення нового співрозмовника, неправильного JSON та зміни моралі, перетворення коротких діалогів і монологів, імена зі знаками й емодзі, зовнішні ремарки та одна відправка в групу. Модель і Telegram у тестах замінені тестовими відповідями.

Статус: локальні тести пройдено; код підготовлений до викладки через `./deploy.sh "редактор і структура сцен"`. Якість гумору та збереження всіх смислових фактів реальною моделлю — **NOT VERIFIED**. Перевіряти за наступними природними груповими випусками, без ручного запуску.
